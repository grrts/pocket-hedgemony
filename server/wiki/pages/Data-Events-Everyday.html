Everyday events data

Every value in the game's everyday events config, exactly as the game reads it. This page is made from packages/rules/data/domain/events-everyday.json each time the config changes, so it always matches the game. How these values are used is explained on Historical Events.

Keys are written as in the config file. Shares are fractions (0.25 is 25 %), and values marked (provisional) are placeholders that may still change in balancing. Inventions are shown by id and name; see Research data.

Everyday events (domain/events/spec.md §5.22, EVT-115 to EVT-128; feedback 152). Small choices about the realm's own people and stores, drawn from what the game already holds: its officials, lords, ruler and heir, and food stores, and plague reaching a province of the player's (EVT-130: not drawn; plague fires it). Each realm draws one every `months_between` months (a range), never while the player has an event waiting; the player's realm never draws the same event again within `rest_years` (EVT-134). `where` limits an event to realms in those regions or wider regions (exploration-regions.json), `from` and `to` to those years (EVT-133). `weight` is how often an event is drawn among the ones that can happen; `needs` names what it is about. Options list their effects in the engine's small vocabulary (gold, loyalty, official, lands, heir, heir_risk, food_back, new_lord, quarantine, care; and for an event about a province, EVT-135: food in months of eating, people and recruits as a share, light_tax in years); `ai` weights the AI's pick; `needs` on an option hides it when the realm lacks what it asks. `{words}` in braces are filled with the names of who and where. Every number is a placeholder for balance.
