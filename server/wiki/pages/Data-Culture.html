Culture data

Every value in the game's culture config, exactly as the game reads it. This page is made from packages/rules/data/domain/culture.json each time the config changes, so it always matches the game. How these values are used is explained on Culture.

Keys are written as in the config file. Shares are fractions (0.25 is 25 %), and values marked (provisional) are placeholders that may still change in balancing. Inventions are shown by id and name; see Research data.

Culture config (domain/culture/spec.md §10), from culture/culture-config.example.yaml version 1. All numbers are placeholders; '_provisional' lists the keys still being balanced. 'tongues_added' are tongues the design or the feature files name with their family.
