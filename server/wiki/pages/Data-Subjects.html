Subjects data

Every value in the game's subjects config, exactly as the game reads it. This page is made from packages/rules/data/domain/subjects.json each time the config changes, so it always matches the game. How these values are used is explained on Subjects.

Keys are written as in the config file. Shares are fractions (0.25 is 25 %), and values marked (provisional) are placeholders that may still change in balancing. Inventions are shown by id and name; see Research data.

Placeholder balance values for subjects-design.md. Loyalty steps are the lords' steps (country stats 5.5). No percentage meter. Copied from subjects/config/subject-rules.json. Keys under reasons marked from_design are the design's own numbers (subjects-design 4, 5) that the source config does not list.
