Government data

Every value in the game's government config, exactly as the game reads it. This page is made from packages/rules/data/domain/government.json each time the config changes, so it always matches the game. How these values are used is explained on Government.

Keys are written as in the config file. Shares are fractions (0.25 is 25 %), and values marked (provisional) are placeholders that may still change in balancing. Inventions are shown by id and name; see Research data.
