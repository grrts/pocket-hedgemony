Time and turns data

Every value in the game's time and turns config, exactly as the game reads it. This page is made from packages/rules/data/domain/time-and-turns.json each time the config changes, so it always matches the game. How these values are used is explained on Time and Turns.

Keys are written as in the config file. Shares are fractions (0.25 is 25 %), and values marked (provisional) are placeholders that may still change in balancing. Inventions are shown by id and name; see Research data.

Time and turns (domain/time-and-turns/spec.md). Turn order from DECISIONS X-2, weeks X-3, seasons X-4, start date X-25 (the start scenario's day, packages/rules/data/scenarios), victory timing X-12, the 1939 cut X-14. Wet seasons are placeholders; ages from event-tree/data/ages.yaml.
