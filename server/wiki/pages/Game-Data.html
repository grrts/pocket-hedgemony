Game data

Every number the game plays by, straight from its config: unit strengths, building sizes, invention costs, break points, prices, chances and timings. These pages are made from the game's rules files in packages/rules/data each time they change, so they always match the game. The other wiki pages explain what the values do; Formulas shows how the game combines them.

Keys are written as in the config. Shares are fractions (0.25 is 25 %). A value marked (provisional) is a placeholder that may still change in balancing.
