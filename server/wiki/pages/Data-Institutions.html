Institutions data

Every value in the game's institutions config, exactly as the game reads it. This page is made from packages/rules/data/domain/institutions.json each time the config changes, so it always matches the game. How these values are used is explained on Institutions.

Keys are written as in the config file. Shares are fractions (0.25 is 25 %), and values marked (provisional) are placeholders that may still change in balancing. Inventions are shown by id and name; see Research data.

Institutions (domain/institutions/spec.md, INST): the Empire and the Shogunate. Values from the institutions design of 18 October 2026 (/mnt/project-files/institutions/institutions-design.md). Every number is a placeholder balancing knob. members_1444 is the design's worked X-13 match of the catalogue's imperial estates to map realms (OQ-INST-1: the Teutonic Order, nominal in the catalogue, is left out as the design lists it).
