Exploration data

Every value in the game's exploration config, exactly as the game reads it. This page is made from packages/rules/data/domain/exploration.json each time the config changes, so it always matches the game. How these values are used is explained on Exploration and Colonies.

Keys are written as in the config file. Shares are fractions (0.25 is 25 %), and values marked (provisional) are placeholders that may still change in balancing. Inventions are shown by id and name; see Research data.

Exploration (EXPL) config, from exploration/exploration-design.md v1 sections 2-8 and its section 10 decisions. Every number is a placeholder of the design except unlock_age (decided). Numbers that belong to naval (supply, reach, out-of-supply loss, docking, the exploration ship rows) are repeated under 'naval' as this context reads them (naval-design 3.3, 6.3, 6.4, 7.2). Colonial range per government form is government's (government.json forms.*.colonial_range).

comment\_unlock\_later\_ages: D-EXPL-3: a region outside unlock_age's region list opens with the first age that starts later than unlock_age and covers it (age_of_atlantic_empires for north_america, age_of_reformations for middle_east and central_asia), read from exploration-regions.json.

comment\_governor\_slots: D-EXPL-4: the base is 2 with S5, else 1 with S3; T8 and T9 each add 1 to any base.
