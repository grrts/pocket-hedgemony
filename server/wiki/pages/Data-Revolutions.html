Revolutions data

Every value in the game's revolutions config, exactly as the game reads it. This page is made from packages/rules/data/domain/revolutions.json each time the config changes, so it always matches the game. How these values are used is explained on Revolutions.

Keys are written as in the config file. Shares are fractions (0.25 is 25 %), and values marked (provisional) are placeholders that may still change in balancing. Inventions are shown by id and name; see Research data.

Revolutions (domain/revolutions/spec.md): revolutions/generated/runtime/*.json plus reference.yaml and the balance values of revolutions-design.md section 7 and 12. All numbers are placeholders.
