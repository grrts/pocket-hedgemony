Tribes data

Every value in the game's tribes config, exactly as the game reads it. This page is made from packages/rules/data/domain/tribes.json each time the config changes, so it always matches the game. How these values are used is explained on Tribes and Hunting Grounds.

Keys are written as in the config file. Shares are fractions (0.25 is 25 %), and values marked (provisional) are placeholders that may still change in balancing. Inventions are shown by id and name; see Research data.

Tribes (domain/tribes/spec.md, TRIBE): tribal realms of North America and their hunting grounds. Values from the tribes design of 18 October 2026; every number is a placeholder balancing knob (DECISIONS rule 4). region_bounds draws each region of tribes.regions as a box of longitude and latitude, read against a realm's capital on the map, since map realms carry no catalogue region. new_tribe_regions, new_tribe_representations, new_tribe_provinces and new_tribes_left_out say which catalogue records the 1444 map adds as new tribes (TRIBE-002 to TRIBE-005); their home points are in packages/rules/data/scenarios/1444/map-nations.json (grows).
