Religion data

Every value in the game's religion config, exactly as the game reads it. This page is made from packages/rules/data/domain/religion.json each time the config changes, so it always matches the game. How these values are used is explained on Religion.

Keys are written as in the config file. Shares are fractions (0.25 is 25 %), and values marked (provisional) are placeholders that may still change in balancing. Inventions are shown by id and name; see Research data.

Religion config (domain/religion/spec.md §10), from religion/config/religion.yaml version 1; every number is a first-pass placeholder. 'patches' and 'event_options' are copied from religion/event-tree-additions (patches.yaml, religion-events.yaml). 'holy_place_names' and 'holder_names' are the display names the feature files use.
