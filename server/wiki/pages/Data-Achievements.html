Achievements data

Every value in the game's achievements config, exactly as the game reads it. This page is made from packages/rules/data/domain/achievements.json each time the config changes, so it always matches the game. How these values are used is explained on Achievements.

Keys are written as in the config file. Shares are fractions (0.25 is 25 %), and values marked (provisional) are placeholders that may still change in balancing. Inventions are shown by id and name; see Research data.

Achievements (domain/achievements/spec.md). tiers and achievements copied from achievements/achievements.yaml, with the harvest ladder (D-ACH-16) and the 1378 start's rows (D-ACH-17) (config v1; the YAML key 'on' renamed 'moment', D-ACH-6; every test number is a placeholder). limits, moments, progress, stores, icons and toast from achievements-design.md sections 2, 5, 6, 7, 8 and 9. narrative_only_events: event ids marked depiction narrative_only in event-tree/data/events (read for ACH-005).
