Diplomacy data

Every value in the game's diplomacy config, exactly as the game reads it. This page is made from packages/rules/data/domain/diplomacy.json each time the config changes, so it always matches the game. How these values are used is explained on Diplomacy.

Keys are written as in the config file. Shares are fractions (0.25 is 25 %), and values marked (provisional) are placeholders that may still change in balancing. Inventions are shown by id and name; see Research data.

Diplomacy context config. 'relations' is copied from country-relations/config/relation-rules.json (relation model, matrix, actions, durations); the rest from diplomacy/diplomacy-rules.json. Every number is a placeholder balancing knob owned by game design. Subject kinds: the engine reads relations.subject_kinds only for labels; joining wars and own diplomacy follow the six kinds of subjects.json (X-8, D-DIPL-10).

stancefriendly, neutral, rival, hostileAt most one stance per perspective (A towards B). A mutual stance record fills both perspectives; a one-way record fills only source towards target. With no stance stored, the game uses the default stance, which is not a historical claim.

#Precedence

When gameplay creates a relation that is incompatible with an existing one, the newer relation wins and ends the older one, except where an action is blocked by 'requires'. When two stored historical records conflict, validation fails: precedence never silently fixes data.

#Arms and fear

Leroy, 19 Oct (DIPL-231 to DIPL-237, F-165): every AI realm keeps a standing army sized against its neighbours, calls men across the whole realm at war and borrows for it, and feels Wary or Threatened beside a much stronger neighbour. There is no rivalry: fear is measured from the armies each month and leaves no lasting tie. Every number is provisional, for the balance model to tune.
